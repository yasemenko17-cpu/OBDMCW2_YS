# Завдання 15. Клієнти без замовлень і найновіше замовлення (складне)

*Тема: підзапити, з'єднання, віконні функції та їх вибір (лекції 5 і 6).*

Інтернет-магазин має таблицю `customer` (2 мільйони рядків) і таблицю `orders` (20 мільйонів рядків) зі стовпцями `id`, `customer_id`, `created_at`, `total`. Через історичний імпорт `orders.customer_id` для частини замовлень дорівнює `NULL` (гостьові замовлення). Є індекс за `orders (customer_id, created_at)`. Потрібно два звіти.

- **Звіт A.** Клієнти, які ніколи нічого не замовляли.
- **Звіт B.** Для кожного клієнта, який має замовлення, його найновіше замовлення (усі стовпці). У клієнта можуть бути два замовлення з однаковим `created_at`.

**Завдання.** Для кожного звіту розгляньте принаймні два способи запису (звіт A: `NOT IN`, `NOT EXISTS`, `LEFT JOIN ... IS NULL`; звіт B: корельований підзапит з `max(created_at)`, `DISTINCT ON`, `ROW_NUMBER()`). Оберіть по одному способу для кожного звіту. Обґрунтуйте вибір за трьома мірками: коректність (з `NULL` і рівними датами), читабельність і ймовірна ціна виконання. Скажіть, що перевірите в плані `EXPLAIN` і як переконаєтесь, що два способи дають однаковий результат.

**Формат відповіді.** Файл `answers/task_15.md`: для кожного звіту порівняння способів, вибраний запит і обґрунтування (до 20 речень загалом).
